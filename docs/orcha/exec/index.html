The 11 reusable agent roles

3 + 2 + 5 + 1▸

Each role is a versioned, testable contract in the delivery repository — see the skill library in the deep view.

Define — Shape the Work 3 roles

Feedback ConverterTurns approved feedback into linked, scoped delivery work
Issue ShaperMakes work executable: outcome, scope, acceptance, demo plan
Delivery ManagerMoves work through its lifecycle states from intake to done

Build — Build in Parallel 2 roles

Lane ProvisionerSets up each isolated lane so parallel work never collides
Environment RunnerStands up, smoke-tests, and resets a full local stack per lane

Prove — Quality, Safety and Packaging 5 roles

Test SelectorPicks the narrowest credible checks for each change, mirroring CI
Demo CapturerProduces screenshots, clips, and diffs as reviewable evidence
Code ReviewerHunts bugs, regressions, missing tests, and risky boundaries
Data Transformation ReviewerReviews data pipeline changes for lineage and schema discipline
PR PackagerAssembles the evidence-backed change package; screens for sensitive data

Human Control — Product Ownership 1 role

Readiness AuditorRenders the go / go-with-risks / no-go evidence brief for the Product Owner

The Orchestrator and the Product Owner sit outside the 11 — coordination and decision are separate concerns. Automation proves and recommends; a human turns the merge key.
