01 · Decide — assessment harness

How an application earns its verdict

An arbitrary application goes in; an auditable decision comes out. Six read-only specialists recover what the product is without ever running it, a deterministic rubric scores the path — adopt, reconstruct, or wrap — and a separate production gate rules on promotion. Three outcomes, never collapsed into one.

02 · Deliver — agentic delivery harness

How a change earns its merge

A scoped issue becomes an isolated agent lane, and every pull request is proven in parallel — changed-area CI, AI review, visual evidence, security policy — until a single readiness verdict puts the final decision in a human hand. Failures return to their lane; accepted lessons re-arm the skills.
