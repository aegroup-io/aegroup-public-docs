Review & experience

Advisory code review · AI

An AI reviewer works the repo's own rubric — bugs, regressions, tests, auth, routing, queues, boundaries. One full receipt per head SHA; advisory by design, so an outage never blocks delivery.

Visual regression gate

Deterministic build, 37 routes captured with Playwright, pixel diff against accepted baselines (warn 0.2% · fail 1.0%), plus an AI design review whose fail blocks. Demo clips ride along as evidence.

Baseline acceptance · human-dispatched

Maintainer-only workflow verifies the official run, exact PR head SHA, artifact identity and digest, and capture manifest before any baseline changes.

Cyber & release

Security manifest policy

Deployment images digest-pinned; long-lived containers need probes, non-root execution, no privilege escalation, dropped capabilities. Exceptions are exact, owned, and expire — the gate fails closed.

Release certification · nightly

Reproducible image + provenance; CycloneDX SBOMs for runtime, Python, and image; three secret scans (tree, image + history, evidence); vulnerability scan blocks HIGH/CRITICAL findings with available fixes.

Credential custody

Jobs that touch source systems carry a credential reference, never a secret. Resolution requires an exact scope match and fails closed — agents and queues never hold passwords, tokens, or keys.

DAST · operator-run

API baseline and auth-flow scans with a versioned alert policy and triage runbooks. Deliberately not a PR gate today.

The loop that runs it

Automation observes, proves, and notifies. Convergence — and every consequential promotion — stays with people.

Orchestrator

Reads labels first, audits scope, picks single-issue or epic mode, hands each lane a bounded contract, and integrates one lane at a time with a tracked test-and-risk table.

Event hooks

Issue and PR activity emits four lifecycle events — task started, blocked, PR opened, ready to merge. A notification adapter can forward them to chat.

Drift monitor · every 10 min

A deterministic, low-token audit compares board status against labels, linked PRs, and failing checks, and publishes a JSON report. Auto-reconcile is deliberately held back.

Evidence becomes memory

Accepted findings update versioned skills, guidance, tests, or runbooks — and harness validation makes the lesson enforceable on the next run.

Failed check · advisory finding · visual regression · policy violation · stale SHA → Return to the owning lane; fix, re-run the narrow checks, push a new head → Stale evidence voided; readiness aggregates again ↺
